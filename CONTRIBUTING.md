# Contributing

1. Add evidence before adding a catalog entry: repository URL, source revision, license, and the exact basis for compatibility claims.
2. Keep runtime verification separate from metadata review.
3. Do not execute upstream install scripts in CI.
4. Add deterministic fixtures and tests for converter or validator changes.
5. Preserve third-party attribution and license notices.

Pull requests should state what is implemented, what remains unverified, and how the change was tested.
