# Project Flow port

Project Flow is an independent Codex-native project-management skill. It provides a small, inspectable workflow for:

- PRD capture and feature decomposition.
- Local task state and progress reporting.
- Test and acceptance evidence.
- Optional, approval-gated GitHub Issue creation.
- Optional, approval-gated Git worktree creation.

It was selected after auditing [oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode), an MIT-licensed Claude-first orchestration project that did not establish Codex support in its metadata. No upstream source files were copied. CCPM was not ported because [CCPM](https://github.com/automazeio/ccpm) already explicitly supports Codex and Agent Skills.
